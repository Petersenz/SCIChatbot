## การแก้

- สืบสาขาและอาชีพจากประวัติคำถามในsessionเดิม รวมคำขอบคุณ/โอเค; เปลี่ยนสาขาล้างอาชีพและปีเก่า; เปลี่ยนอาชีพแทนfocusเดิม; คำถามทั้งคณะไม่ลากสาขาเก่า.
- ไม่ทราบสาขาหรืออาชีพถามกลับ; หลายสาขาไม่เลือกตัวแรก; อ้างอาชีพแรกโดยไม่มีชื่อที่ยืนยันได้ให้ขอชื่อ.

- คำถามระบุอาชีพโดยตรงในห้องใหม่ค้นชื่ออาชีพนั้นได้ แต่ไม่กล่าวอ้างว่าเป็นของสาขาใด.
- คำถามอาชีพ/ค่าเทอมไม่โหลดข่าวและไม่ใช้fuzzyeventrouting; ปี/ภาค/หน่วยกิตและหัวข้ออื่นใช้เส้นทางเดิมที่มีregression.
- เงินเดือน/ทักษะที่ตรงรายการตอบจากstructuredfactsไม่เรียกembedding/LLM; ระบุสาขาและรักษาexperience/proxy/limitations. ถ้าถามจบใหม่แต่หลักฐานห้ามตีความเช่นนั้น แจ้งยังยืนยันไม่ได้.
